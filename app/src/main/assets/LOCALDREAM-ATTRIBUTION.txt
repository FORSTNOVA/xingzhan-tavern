The optional arm64 native helper included in local builds is copied without
binary modification from the locally supplied Local Dream 2.8.1 APK. This
project adds Android packaging, QNN runtime staging, and an opt-in device
smoke-test launcher around that helper. Model weights and Qualcomm QNN runtime
libraries are not bundled in this APK; runtime libraries are staged on-device
from an already installed Local Dream package.
